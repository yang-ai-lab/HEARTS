# HEARTS website (`website` branch)

This branch **is** the deployed site served by GitHub Pages at
<https://yang-ai-lab.github.io/HEARTS/>. It is a self-contained static site —
plain HTML + vanilla JS, no build pipeline and no external CDN at runtime.
(It replaces the previous React/Vite SPA that was built from a separate private
repo and force-pushed here by a GitHub Action.)

## Layout

```
index.html              Single page (Overview / Leaderboard / About / Submit / Citation)
404.html                Redirects old deep links (/about, /submit, …) to in-page anchors
style.css               Compiled Tailwind + @font-face (committed; do not edit by hand)
tailwind.input.css      Source for style.css (edit this, then recompile — see below)
theme.css               Hand-authored layer loaded AFTER style.css: warm Morandi
                        palette + dark mode (html.dark), section banding, Fraunces
                        @font-face, ambient effects, stat/finding cards, leaderboard
                        table. EDIT THIS BY HAND — it is NOT generated by Tailwind.
js/                     models, leaderboard-data, leaderboard-chart, leaderboard-table, main
vendor/                 Chart.js, PapaParse, Lucide (vendored, no CDN)
fonts/                  Self-hosted Inter (body) + Fraunces (display serif), woff2
data/                   merged_metric_results.csv (leaderboard source) + figures
llm_icons/              Model logos
```

## Editing content

- Text / sections: edit `index.html`.
- Leaderboard numbers: edit `data/merged_metric_results.csv`. Scores are computed in the
  browser by `js/leaderboard-data.js` (a faithful port of the original aggregation:
  per-task scores → category means → total). Model display names/types live in `js/models.js`.

## Recompiling CSS (only when class names change)

`style.css` is generated by the Tailwind v4 CLI from `tailwind.input.css`. After changing
classes in `index.html`/`js/**`, regenerate it with the standalone CLI (no Node project needed):

```bash
# one-time: grab the standalone binary for your platform from
# https://github.com/tailwindlabs/tailwindcss/releases  (e.g. tailwindcss-linux-x64)
./tailwindcss -i tailwind.input.css -o style.css --minify
```

Then commit the updated `style.css`.

## Preview locally

`fetch()` of the CSV requires HTTP (not `file://`):

```bash
python3 -m http.server 8000
# open http://localhost:8000/
```

## Deploy

GitHub Pages is configured to serve this `website` branch (root). Committing and pushing
here updates the live site. Keep `.nojekyll` so `js/`, `vendor/`, etc. are served verbatim.
